# Deanery Statement App

Настольное Windows-приложение для сотрудников деканата. Помогает сформировать итоговую ведомость по Excel-выгрузке из Moodle: находит студентов, считает оценки по процентам, учитывает пересдачи и собирает Word-документ по шаблону.

## Возможности

- загрузка `.xlsx`-файлов с оценками из Moodle;
- автоматическое определение дисциплины из имени файла Moodle;
- ручное редактирование данных ведомости: предмет, группа, специальность, преподаватель;
- быстрый выбор значений из справочников и добавление новых значений прямо из формы;
- фильтрация студентов по одному или нескольким индивидуальным номерам Moodle;
- поддержка пустого индивидуального номера, если в выгрузке Moodle он не заполнен;
- сортировка студентов в ведомости по фамилии;
- учет дополнительных попыток: в итоговую ведомость попадает максимальная оценка, остальные попытки отображаются в предварительном просмотре как пересдачи;
- опциональное добавление процентов в итоговую ведомость;
- расчет оценок по правилам из PostgreSQL;
- формирование `.docx`-ведомости по шаблону;
- экспорт в PDF и печать при наличии поддерживаемых программ на рабочей станции;
- управление справочниками предметов, групп, специальностей и преподавателей.

## Интерфейс

Основной сценарий работы:

1. Нажмите `Выбрать Excel-файл` и укажите выгрузку из Moodle.
2. Проверьте найденные данные ведомости и список студентов.
3. При необходимости выберите индивидуальные номера Moodle для фильтрации.
4. Отметьте `Добавлять проценты в итоговую ведомость`, если проценты должны попасть в Word-документ.
5. Нажмите `Сформировать ведомость`.
6. Откройте, экспортируйте в PDF или распечатайте готовый документ.

## Требования

- Windows 10/11;
- Python 3.11+ для запуска из исходников;
- PostgreSQL 14+;
- Microsoft Word или LibreOffice для экспорта в PDF;
- Microsoft Word рекомендуется для удобного просмотра и печати `.docx`.

## Быстрый старт для разработки

Создайте виртуальное окружение:

```bat
python -m venv .venv
.venv\Scripts\activate
```

Установите зависимости:

```bat
pip install -r requirements.txt
```

Создайте базу данных и заполните начальные справочники:

```bat
psql -U postgres -f sql\init_db.sql
psql -U postgres -d deanery_statement_app -f sql\seed_data.sql
```

Создайте рабочий конфиг на основе примера:

```bat
copy config.example.ini config.ini
```

Отредактируйте `config.ini`: укажите хост, пользователя и пароль PostgreSQL.

Запустите приложение:

```bat
python -m app.main
```

Или используйте:

```bat
run.bat
```

## Конфигурация

Пример безопасного конфига хранится в `config.example.ini`.

```ini
[database]
host=localhost
port=5432
user=deanery_app
password=change_me
database=deanery_statement_app

[app]
template_path=app/templates/statement_template.docx
output_dir=output
keep_empty_rows=true

[excel]
header_search_rows=15
data_start_row=2
swap_first_last_names=true
```

Файл `config.ini` не должен попадать в GitHub, потому что может содержать реальные пароли и локальные настройки.

## Формат Moodle Excel

Приложение ищет строку заголовков в первых строках файла и определяет нужные колонки по названиям. Поддерживаются поля:

- имя, фамилия и отчество студента;
- процент выполнения;
- индивидуальный номер Moodle;
- логин студента;
- дата и время начала теста.

Если у студента несколько попыток, итоговая ведомость получает лучшую попытку по проценту. В предварительном просмотре остальные попытки остаются видимыми и помечаются как пересдачи.

## Правила оценивания

Правила берутся из таблицы `grade_rules`.

Начальная шкала:

| Процент | Оценка |
|---:|---|
| 91-100 | 5 |
| 81-90 | 4 |
| 71-80 | 3 |
| 0-70 | 2 |

Границы диапазонов включительные.

## Структура проекта

```text
deanery_statement_app/
  app/
    db/                 # подключение к PostgreSQL и репозитории
    resources/          # стили и иконки интерфейса
    services/           # парсинг Excel, генерация DOCX/PDF, печать
    templates/          # шаблон ведомости
    ui/                 # окна и элементы интерфейса
    config.py
    main.py
  installer/            # скрипт Inno Setup
  sql/                  # создание БД и начальные данные
  tests/                # тесты
  build_exe.bat
  config.example.ini
  requirements.txt
  run.bat
```

## Сборка exe

```bat
build_exe.bat
```

После сборки исполняемый файл появится в:

```text
dist\DeaneryStatementApp\DeaneryStatementApp.exe
```

## Создание установщика

1. Установите Inno Setup.
2. Соберите `.exe` через `build_exe.bat`.
3. Откройте `installer\setup.iss` в Inno Setup Compiler.
4. Нажмите `Compile`.

Готовый установщик будет создан в `installer\Output`.
